# Arabic glossary

The Arabic UI uses simple Modern Standard Arabic that reads naturally in both Egypt and Saudi
Arabia: short sentences, everyday verbs, no legal or technical phrasing, and no dialect
(avoid words such as «تاني» or «جاب»). Use these terms everywhere so the same thing always has
the same name.
